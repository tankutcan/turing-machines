Payoff distribution and responses to constant strategies

The 34 always-defectors output D on every eight-bit opponent code; the 34 always-cooperators output C. No two-state machine defects against all of the former and cooperates with all of the latter.

The closest is machine 7: it defects against 24 of 34 always-defectors and cooperates with 30 of 34 always-cooperators (54 of 68 correct). Its mean payoff over the full ensemble is 1.980392.

A narrower rule-based definition gives a different answer. There are 16 tables with W identically 0 and 16 with W identically 1. Machines 7, 39, 88, 216 distinguish these two smaller classes perfectly. The broader behavioral classes also contain programs with mixed W entries whose final outputs are nevertheless constant.

For example, machine 39 simply outputs the opponent's penultimate code bit, W(2,1). That single rule bit perfectly identifies the constant-W tables, but it need not determine a program's final behavior.

Model and archive

All 4⁴ = 256 labeled tables with two states and two read symbols. Each table entry stores an output bit W and a next-state bit S−1; motion is fixed rightward. Entry order is (1,0), (1,1), (2,0), (2,1), with W then S−1. Machine IDs read cell 0 as the least significant bit. IDs differ from the full Turing-machine census.

Both readers reset to state 1, scan the other program from cell 0 through cell 7 without changing it, and choose the eighth emitted bit: 1 = cooperate, 0 = defect. A machine's own table stays fixed. The archive includes 32,640 distinct-pair games and 256 games between identical copies. Main graph statistics exclude self-loops.
